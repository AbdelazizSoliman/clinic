# Advanced analytics

`Analytics::AdvancedSummary` is a query/service layer shared by the dashboard and CSV export. Every dataset starts from the current organization and an authorized branch set. Date presets are today, last 7 days, last 30 days, current month, and bounded custom ranges in the organization timezone (Cairo by default). Headline metrics compare with the immediately preceding equal period; percentage change is omitted when the prior denominator is zero.

Datasets cover sales by channel/category/brand/product/payment method and discount; purchase spend/volume/supplier/cost trend/overdue/partial receipt/observed lead time; physical/available/reserved/valued/expired/near-expiry/quarantined/aged inventory and transfers; privacy-conscious customer frequency/loyalty/wallet use; aggregate prescription workload and review turnaround; aggregate safety finding severity/rules/acknowledgements/overrides; privacy-normalized search/zero-result/selection trends; ledger-derived loyalty and wallet liabilities/activity; returns/refunds/dispositions/channel; and branch sales, fulfilment, POS, inventory, purchasing, returns and transfer comparisons.

Gross sales are non-cancelled online totals plus completed POS totals. Net sales subtract completed refunds. Average transaction value divides gross sales by transaction count. Inventory value is on-hand quantity × batch unit cost. Available units subtract active reservations and returned quarantine. Wallet liability and outstanding loyalty points derive only from append-only ledger expressions. Supplier lead time is explicitly an observed interval, not an SLA; inventory turnover is not labelled as accounting turnover because the required accounting inputs are absent.

Branch-restricted staff receive only accessible branch aggregates, including branch-provenanced search events. Clinical results are aggregates and do not expose patient histories. CSV uses the same scoped dataset, tenant timezone, authorization, and formula-injection escaping. Dashboard links use existing authorized operational report routes for audit drill-downs.
