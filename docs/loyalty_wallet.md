# الولاء والمحفظة — المرحلة 23

## فصل المجال ومبدأ الدفتر

النقاط وحدات ترويجية وليست نقوداً. المحفظة قيمة مالية بالجنيه المصري محفوظة بالقروش الصحيحة. لكل عميل `LoyaltyAccount` و`WalletAccount` مستقلان، والرصيد مشتق من القيود غير القابلة للتعديل أو الحذف. لا توجد أعمدة رصيد مخبأة؛ كل تصحيح قيد تعويضي جديد.

## القواعد والكسب والاستبدال

`LoyaltyRule` يقدم قاعدة كسب (نقاط لكل حد إنفاق) وقاعدة استبدال (نقاط مقابل قروش) مع حدود وفعالية ومدة صلاحية اختيارية، دون لغة قواعد عامة.

ترتيب الحساب: أسعار اللقطة ← العروض والكوبونات ← خصم النقاط ← دفع المحفظة ← المتبقي COD/نقد/طرفية. المحفظة ليست خصماً. الإنفاق المؤهل صافي البضاعة بعد الخصومات واستبدال النقاط، دون التوصيل أو الجزء المدفوع بالمحفظة. يكسب الطلب عند `delivered`، ويكسب POS المعرف بعميل عند `completed` فقط.

ينشئ الاستبدال قيد `redeem` ويخصصه إلى أقدم القيود الدائنة انتهاءً. إنشاء الطلب وPOS يقفل الحساب ويقيد داخل معاملة الإتمام، لذلك لا يحتاج حجزاً طويل العمر ولا يترك holds لسلة مهجورة.

انتهاء النقاط قيد `expire` صريح وتخصيص مرتبط بالدفعة. `Loyalty::Expire` آمن عند الإعادة؛ جدولة تشغيله إنتاجياً غير مفعلة تلقائياً.

## المحفظة والمدفوعات

مصادر الائتمان الداخلية: استرداد مرتجع، تعديل مدير موثق، رصيد تجريبي، وعكس دفع طلب ملغى. لا يوجد شحن خارجي أو تحويل أو سحب.

يحفظ الطلب النقاط والخصم ودفع المحفظة والمتبقي عند الاستلام، مع قيد تطابق الإجمالي. يدعم POS `wallet` ضمن `PosPayment` والمزج مع النقد/الطرفية. يلزم عميل مرتبط صراحة؛ البيع المجهول لا يكسب أو ينفق.

المحفظة لا تدخل الصندوق: التسوية تظل الافتتاح + النقد المقبوض − الاسترداد النقدي.

## المرتجعات

استرداد المحفظة ينشئ `Refund` وقيد `WalletLedgerEntry#refund` في معاملة واحدة. عند اكتماله ينشأ `earn_reversal` نسبي و`redemption_restore` نسبي حتى سقف الأصل. القيود الأصلية لا تتغير. إذا أنفق العميل النقاط قبل المرتجع يسمح دفتر الولاء برصيد سالب مضبوط حفاظاً على صحة المحاسبة.

## الأمان والتقارير

الحسابات لعملاء فقط، والمبالغ أعداد صحيحة موجبة، والأنواع مقيدة، ومفاتيح idempotency فريدة. تقفل خدمات الإنفاق الحساب قبل الفحص والكتابة. العميل يرى حسابه فقط، والتعديلات والقواعد للمدير. لا توجد بيانات سريرية أو PAN/CVV أو أسرار.

يسجل التدقيق إنشاء القواعد والتعديلات والكسب والاستبدال والعكس وحركة المحفظة. تعرض صفحة العميل التاريخ الآمن، ويجمع التقرير القيود والتزامات الأرصدة بنطاق القاهرة ويصدر CSV.

## الحدود ومرحلة 24

لا عضويات أو إحالات أو هدايا أو سحب/تحويل أو بوابة دفع أو بطاقات أو فروع متعددة. تفعيل جدول انتهاء النقاط وسياسات مالية أوسع ومزود دفع مستقبلي هي حدود مرحلة 24 وما بعدها.
